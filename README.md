Mario Jump é um jogo simples e divertido inspirado no clássico estilo “endless runner”, onde o jogador controla o personagem para desviar de obstáculos utilizando mecânicas de pulo e tempo de reação.

O projeto foi desenvolvido com foco em praticar conceitos fundamentais de desenvolvimento front-end, especialmente manipulação de DOM, lógica de jogo e interatividade com JavaScript. A proposta segue a ideia de jogos como o dinossauro do Chrome, onde o desafio aumenta progressivamente conforme o tempo de jogo.

Durante o desenvolvimento, foram implementados elementos essenciais de um jogo 2D, como detecção de colisão, animações de personagem, controle de ações (pulo), e sistema básico de pontuação. Além disso, o projeto busca oferecer uma experiência leve, podendo ser executado diretamente no navegador.
